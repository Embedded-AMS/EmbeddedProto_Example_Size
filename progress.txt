# Size Comparison Tool - Progress Log

## Codebase Patterns
- The project uses CMake for building both desktop and embedded targets
- Existing build.sh script handles code generation and compilation
- STM32 project exists in F446RE_EmbeddedProto/ directory with STM32CubeIDE-generated makefiles
- Symbol tracking and map analysis tools already exist
- EmbeddedProto, NanoPB, and ArduinoJson are available as submodules
- ARM toolchain is located in STM32CubeIDE plugins directory (e.g., /home/bart/st/stm32cubeide_1.4.0/plugins/com.st.stm32cube.ide.mcu.externaltools.gnu-tools-for-stm32.*/tools/bin)
- Build configuration uses -Os optimization and gc-sections for size optimization
- The Release/ and Debug/ directories contain pre-generated makefiles from STM32CubeIDE

- **Learnings for future iterations:**

  - ARM toolchain path must be added to PATH for make to work
  - The makefile already uses -Os and gc-sections (configured in STM32CubeIDE)
  - EmbeddedProto venv must be activated for code generation
  - Clean builds take longer due to recompiling all HAL drivers
  - main.cpp uses #define SIZE_TEST, EAMS, or neither (for nanopb) to select library
