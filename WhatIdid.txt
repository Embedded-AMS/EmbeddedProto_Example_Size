GoogleProtobuf install:
  sudo apt-get install g++ git bazel
  git checkout https://github.com/protocolbuffers/protobuf/releases/latest GoogleProtobuf
  cd GoogleProtobuf
  git submodule update --init --recursive
  bazel build :protoc :protobuf

The compiler can then be installed, for example on Linux:

cp bazel-bin/protoc /usr/local/bin



Running the desktop build:
  ./build.sh
